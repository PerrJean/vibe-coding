# 0000 — Convention

Le registre de ce dépôt suit la convention commune, `modele/registre/0000-convention.md` :
un point par fichier, six champs, statut toujours écrit, section `## Tranché`. Seules les
étapes sont propres au dépôt.

## Étapes de ce dépôt

- `guide` : README, POUR-ALLER-PLUS-LOIN, LEXIQUE, ANNEXE.
- `modele` : le modèle de projet, `modele/`.
- `global` : skills, hooks et installateurs de `global/`.
- `outils` : `outils/` et les workflows de `.github/`.
- `garde` : la garde de publication, `.githooks/`.
